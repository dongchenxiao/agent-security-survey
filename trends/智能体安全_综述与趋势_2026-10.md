## 1. 概述

智能体安全（LLM Agent Security / Agentic AI Security）研究大语言模型从"对话工具"进化为具备工具调用、检索增强、持久记忆、自主规划与多智能体协作能力的智能体之后产生的全新安全问题。与传统的模型层安全议题不同，智能体安全的中心问题是：**当不可信的外部内容（网页、工具输出、文档、记忆、传感器流）可以驱动一个拥有真实权限（执行代码、调用 API、支付、操控物理设备）的系统时，如何保证其行为完整、可控、可追责**。其研究版图覆盖：提示注入（直接/间接/多模态/长程/物理）攻防、工具与 MCP/技能供应链安全、记忆与持久状态安全、多智能体系统风险、智能体自主网络攻防、评测基准与红队方法学、身份/权限/授权架构、系统防御与安全训练、治理与真实事件，以及 RAG 与具身两个专门域。

新语料 2499 篇的筛选结果给该版图标注了清晰的权重（K 数为新语料判定）：

| 子主题 | K | 子主题 | K |
|---|---|---|---|
| A1 提示注入攻防 | 63 | A6 身份权限与授权架构 | 80 |
| A2 工具/MCP/技能供应链 | 51 | A7 评测基准与红队方法学 | 110 |
| A3 记忆与持久状态安全 | 31 | A8 系统防御与安全训练 | 96 |
| A4 多智能体系统风险 | 64 | A9 治理标准与真实事件 | 75 |

| C1 具身智能体安全 | **377** | 合计 | 1060 |

三条结构性事实值得注意：**其一**，C1 具身安全以 377 篇成为最大子主题（占 K 的 35.6%），2026 年 9–10 月的增量批几乎以 VLA/机器人攻防为主线，安全研究重心正大规模向物理域迁移；**其二**，非具身子主题中 A7（评测，110）、A8（系统防御，96）、A6（授权，80）居前，"防御—评测—授权"三角仍是主干；**其三**，A3 记忆（31）与 B1 RAG（34）在新语料中占比下降，相关问题正在被吸收进 A2/A8/A9 的体系化框架而非独立扩张。

本领域的演化轨迹在旧版四阶段划分上继续延伸（以下篇数均为旧版关键词库计数）：2023 年概念形成（15 篇级）、2024 年智能体化与攻击面爆炸（107 篇级）、2025 年爆发与系统范式定型（377 篇级）、2026 年成熟与体系化（816 篇级），而 **2026 年 9–10 月（新语料 K=612）标志着第五个节点：共同进化与形式化深化**——攻防进入自动迭代飞轮，治理开始由真实事件库驱动，理论工作从"划界不可能性"走向"可度量化"。整体来看，智能体安全已完成从"提示注入的猫鼠游戏"到"覆盖模型—系统—生态—物理—治理五层的独立研究方向"的演化。

## 2. 发展脉络

### 阶段一：2023–2024 萌芽期（概念形成与攻击面爆炸）

**2023：提示注入从案例走向形式化。**

- **2307.16888《虚拟提示注入（VPI）》**：首次形式化"虚拟提示注入"，揭示指令微调 LLM 可被训练期后门劫持；
- **2308.01990《提示注入到 SQL 注入》**：证明 LLM 集成 Web 应用中提示注入可级联为 SQL 注入，打通 AI 风险与传统软件安全；
- **2309.02926《LLM 集成应用 RCE》**：证明提示注入可触发任意代码执行；
- **2310.12815《提示注入攻防形式化基准》**与 **2311.01011《Tensor Trust》**（12.6 万条攻击众包数据）：建立形式化建模与大规模数据两条评测基线；
- **2302.12173《间接提示注入》**（新语料核心集收录，2200 引）：确立间接注入（IPI）作为智能体时代的主导威胁范式。

**2024：智能体化与防御体系化起步。**

- **2402.06363《StruQ》**：结构化查询防御，确立"输入表示层隔离指令与数据"范式；
- **2402.06664《LLM 智能体可自主攻陷网站》**与 **2404.08144《自主利用一日漏洞》**：攻击能力评估从玩具场景推向真实网站与真实 one-day 漏洞；
- **2403.02691《InjecAgent》**：首个工具集成智能体间接注入标准基准；
- **2403.02817《Morris-II AI 蠕虫》**：自复制对抗提示实现 GenAI 应用间零点击蠕虫式传播；
- **2406.09187《GuardAgent》**：首个"以智能体护智能体"的护栏框架；
- **2410.02644《Agent Security Bench（ASB）》**与 **2410.05451《SecAlign》**：综合攻防基准与偏好优化训练防御双双成型；

- **2412.13178《SafeAgentBench》**：安全评测延伸到具身智能体任务规划。

### A1 提示注入攻防（K=63）

攻击侧从"能否注入"转向"检索保证、真实流行度与协议级利用"，防御侧与理论侧同步收紧：

- **2601.17548《编码智能体注入脆弱性系统分析》**：系统分析 skills/tools/protocol 三层生态在 agentic coding 助手中的注入面（新语料高被引，44 引）；
- **2604.27202《野外 IPI 实证》**：12 亿 URL/2480 万主机普查，约 70% 真实 IPI 藏于非渲染 HTML；
- **2603.15714《大规模公开 IPI 红队竞赛》**：464 名参赛者 27.2 万次攻击，13 个前沿模型全部被攻破；
- **2605.17634《智能体可能永远会落入注入》**：以情境完整性重构提示注入并给出不可能性结果；
- **2606.27567《指令-数据不可分不可能性定理》**：共享嵌入架构下完美注入防御在数学上不可能，类比冯·诺依曼代码-数据混淆。

观察记录补充：注入已扩展至服务商侧、阶段式/马赛克多轮与边界审计，多模态视觉/音频载体与控制符抹除思维链成为新通道。

### A2 工具 / MCP / 技能供应链安全（K=51）

技能生态从"新兴风险"变为被大规模证伪的供应链主干，蠕虫与凭证问题完成闭环：

- **2601.10338《Agent Skills in the Wild》**：42,447 个技能大规模实证，26.1% 含漏洞，确立技能生态为重大供应链攻击面；
- **2602.20156《SkillInject》**：技能文件注入基准，前沿模型 ASR 达 80%；
- **2602.20867《SoK: Agentic Skills》**：技能生态的系统化综述（新语料该主题最高被引，133 引）；

## 4. 趋势总结与展望

1. **具身/VLA 成为最大增量域与新主战场**：C1 以 377 篇 K 占新语料 35.6%，2026-09/10 增量批几乎以 VLA 攻防为主线——物理对抗补丁覆盖感知全链路、动作级越狱与持久后门成对涌现、运行时护栏（安全过滤、回滚、保形弃权、认证防御）约占具身 K 类一半（观察估计）、专用基准密集发布（2610.06122、2610.09294 已入库，RoboJailBench（`2605.19328`）/RoboPAIR（`2410.13691`）等）。数字域与物理域的攻防节奏正在对齐，具身安全将从"分支方向"变为"默认场景"。
2. **攻防进入共同进化飞轮，评测方法学同步升级**：攻击侧红队自动化（几何红队、贝叶斯红队智能体、人机协同、MetAdv（`2508.06534`）虚实对抗平台）与防御侧自进化（蒸馏攻击轨迹的自进化防御、统计验收门控）在 2026 秋成型，叠加 GPT-Red（2607.26115）自博弈与 SecOPD（2608.21500）蒸馏压制，"一次性攻防结论"失效；A7（K=110）成为非具身最大子主题正是这一压力的体现——ASR 度量效度、防御保证分级、solve rate 抗作弊指标成为下一代评测的标配。
3. **确定性系统防御完成工程化落地**：eBPF 溯源、参考监控、签名证据账本、提交时状态绑定等"内核级"机制从论文走向参考实现，与 AgentSys（2602.07398）、SOUNDGATE（2607.14166）、强制访问控制（2601.11893）、CaMeLs（2601.09923）、PACT（2605.11039）汇合成"秘密不进模型、能力可撤销可审计、行为可追责"的完整信任栈；防御范式三阶跃迁（模型修补→系统设计→确定性强制+共同进化）在秋季语料中得到确认。
4. **供应链攻击面沿"协议 → 技能 → 多模态 → 物理资产"持续下沉**：MCP 规范级弱点（2601.17549）之外，技能链劫持、技能包图像载毒、3D 资产投毒与机器人技能市场信任验证把供应链推向每一种可分发的资产形态；配合 AgentWorm（2603.15727）的生态级传播与 89.6% 技能凭证泄露（2604.03070），供应链治理（审查门控、最小权限、信任链验证）成为平台厂商的当务之急。
5. **真实事件驱动的治理研究成型**：AIR 事件库 487 例、wiki 协同写入事件、2026 年 OpenAI-HuggingFace 事件、实验室越界事件与手机智能体滥用实证，使 A9（K=75）从立场文转向可检验的危机信息学与问责工程；信任-授权失配（2512.06914）与 agentic 内部威胁（2510.05179）提供了制度设计的靶心，EU AI Act、ISO 13482/13849 与分级监管构成合规响应主线。
6. **理论化从"划界"走向"度量"**：不可能性定理底座（2604.06436、2606.27567、2605.17634）之上，秋季出现攻击严重度反事实度量、ASR 效度检验、防御保证分级、隐蔽谎言攻击上界、平均场博弈建模与技能契约形式验证——理论工作开始输出可判定、可校准的工程前置判断；记忆作为授权面的结论（2609.01836、2606.24322）亟需写回审计、来源绑定与可验证遗忘的工程标准，是下一阶段最明确的缺口之一。
